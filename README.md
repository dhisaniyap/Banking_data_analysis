SQL-Based Banking Data Analysis

Overview:

This project analyzes a banking dataset to understand customer behavior, account usage, and transaction activity.


What I Did:
* Segmented customers by age group, region, and activity status
* Identified customers with multiple accounts and those who closed all accounts using aggregate functions
* Analyzed account type distribution and evaluated average and total balances
* Assessed transaction activity, including volume, total transaction value, and channel usage
* Detected unusually high transactions by comparing values against overall averages
* Performed joins across customer, account, and transaction tables to derive business insights

Key Insights:

* Certain regions have higher customer and transaction activity
* Savings accounts are the most commonly used account type
* Customers in specific age groups are more active
* Observed unusually high transactions based on comparison with overall average values

Tools Used:

SQL (MySQL)
